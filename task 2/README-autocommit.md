Autocommit helper
=================

Run this from PowerShell:

```powershell
pwsh -File .\task 2\autocommit.ps1
```

Optional custom message:

```powershell
pwsh -File .\task 2\autocommit.ps1 -Message "Your commit message"
```

Optional push after commit:

```powershell
pwsh -File .\task 2\autocommit.ps1 -Push
```
